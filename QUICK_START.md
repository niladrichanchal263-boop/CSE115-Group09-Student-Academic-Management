# Quick start for the group

1. Download/extract the repository folder.
2. Open a terminal in this folder.
3. Compile: `gcc -std=c11 -Wall -Wextra -pedantic main.c -o inventory_manager`
4. Run: `./inventory_manager` (Windows: `inventory_manager.exe`).
5. Follow `README.md` for the demo sequence.
6. Execute the manual test cases and record actual results.
7. Update `support/REFERENCES.md` with the real sources/tools used.
8. Replace report/presentation drafts if actual test outcomes or instructor feedback require changes.
