Project title
Inventory & Sales Manager: A Menu-Driven Inventory and Sales Tracking System in C
Problem statement
Small shops and businesses need a simple way to maintain product records, monitor available stock, record sales, and calculate sales totals. Managing these tasks manually can lead to calculation errors, inaccurate stock counts, and difficulty locating product information.

Our project will develop a menu-driven C application that manages product information and supports basic inventory and sales operations.
Project objectives
The application should allow a user to:
- Add new products with unique product IDs.
- Display the available product inventory.
- Search for a product using its ID.
- Update product information and stock quantities.
- Record sales and automatically reduce inventory.
- Calculate the total price of a sale.
- Generate a basic sales summary.
- Save and reload records between program executions, if file handling is included in the agreed scope.
