# Demo Script — Current Development Stage

**Current scope:** main-menu framework only. Do not present inventory, sales,
reporting, or persistence as working features until integrated and verified.

## Short demonstration
1. Compile and run the current `main.c`.
2. Show the five-option menu.
3. Enter options 1–4 and show the placeholder responses.
4. Enter an invalid number and show the error message.
5. Enter 5 to exit.
