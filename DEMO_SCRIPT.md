# One-minute demo recording script

**Target length:** approximately 60 seconds. Record the actual program running on your computer; this file is a script, not a prerecorded video.

## Before recording
- Compile the code and run it from the repository root.
- Use a clean demo dataset or back up and reset the CSV files.
- Close unrelated windows and make the terminal text readable.
- Ensure no personal data is visible.

## Suggested narration and actions
- **0–5 sec:** Show the project title and state that it is a menu-driven inventory and sales manager written in C.
- **5–15 sec:** Add product `101`, `Notebook`, `Stationery`, price `80`, stock `10`, threshold `3`.
- **15–23 sec:** Display inventory and search for product `101`.
- **23–35 sec:** Record a sale of 2 units and show the stock dropping from 10 to 8.
- **35–43 sec:** Attempt to sell 99 units and show the rejection without stock change.
- **43–52 sec:** Show sales summary and low-stock report (if the sample stock/threshold triggers it).
- **52–60 sec:** Save and exit; state that records are stored in CSV files and can be loaded on the next run.

## Recording checklist
- Record the screen, not a slide deck pretending to be a live demo.
- Use the actual submitted source code and build.
- Do not claim a test passed unless you observed the result.
- Save the final clip as `others/DEMO_VIDEO.mp4` and check it plays before upload.
